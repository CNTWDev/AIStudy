# phy-shanghai 校对报告（上海公办物理，含六年级科学基础）

## 结论（先看这里）

1. **高中教材出版社写错了。** 上海 2020 新教材高中物理由**上海科学技术出版社**出版（上海教委目录里简称“沪科技”），由上海市中小学（幼儿园）课程改革委员会组织编写，蒋最敏、高景主编。不是包里写的“沪科教版 = 上海科技教育出版社”。上海科技教育出版社出的是外省用的另一套书，章节完全不同。
2. **初中物理教材已经换成新版，包里的初中目录是旧版。** 2024 年秋起，上海启用《义务教育教科书（五·四学制）物理》（上海科学技术出版社，高景主编，八年级上册到九年级下册）。包里按旧版二期课改目录编排（八上 第一章 声、第二章 光、第三章 运动和力；八下 第四、五章；九上 第六章 压力与压强、第七章 电路；九下 第八、九章）。新版章号和年级分布都变了：
   - 八上：第1章 测量、第2章 机械运动、第3章 声现象、第4章 光现象……
   - 九上：第10章 内能、第11章 静电与电流、第12章 欧姆定律、第13章 电功率
   
   所以“比热容、内能、热机”从八下移到了九上。“密度、压强、浮力”不在新版九上。
3. **七年级已经不开设科学课。** 新课程下，科学只在六年级开设（每周 2 课时），七年级改设生物学、地理；化学提前到八年级，物理在 8–9 年级。教育部目录也写明《科学（五·四学制）》只覆盖一至六年级。包里 4 个 G7“科学”知识点已改为 G6，建议 stages 去掉 G7。
4. **高中单元名混用了人教版章名。** 例如“第5章 抛体运动 / 第6章 圆周运动 / 第7章 万有引力与宇宙航行 / 第8章 机械能守恒”。上海版实际是：第五章 曲线运动（平抛和圆周都在这一章）、第六章 万有引力定律、第七章 机械能守恒定律、第八章 牛顿力学的局限性与相对论初步。已全部改为上海版章名。
5. **选择性必修第三册在高三第一学期，不在高三第二学期。** 依据是上海教委 2026 年秋季目录：选必二、选必三练习部分都标“高三年级第一学期”。已把 10 个 G12“下”改为“上”。
6. **补了 16 个缺漏知识点**，包括相对论初步、力学单位制、圆周运动的应用、静电感应/静电平衡、测金属丝电阻率、机械波的反射和折射、发电机与电动机、电磁振荡与电磁波、传感器、分子速率分布、液体和固体、量子力学原子模型、原子核组成与粒子物理，以及初中新版的声波的应用、焦耳定律、家庭电路。

统计：fix 118 条（大部分是 unit 改成官方章名），add 16 条，remove 0 条，unverified 7 条。

## 事实错误与其他修正

- PSH-ELEC-16：平行板电容公式 C=εS/(4πkd) 中的 ε 应写成相对介电常数 εr，已改。
- PSH-MAG-06：
  - desc 里的“电磁振荡与传感器简介”属于选必二第八、九章，已移出，另建知识点。
  - 先修 PSH-SOUND-06（机械波，高二下）晚于本知识点（高二上），先修关系倒挂，已改成“有帮助”。
- PSH-OPT-09：2025 年等级考点评明确考了偏振，已改 hot=true。
- 其余公式、常数抽查无误：g=9.8 N/kg，1 标准大气压≈1.01×10⁵ Pa，水的比热容 4.2×10³ J/(kg·℃)，单摆周期，光电效应方程等。
