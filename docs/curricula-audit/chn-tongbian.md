# chn-tongbian（统编语文 G1–G12）校对报告

## 结论
1. 版本说错了：上海义务教育用的是《义务教育教科书（五·四学制）·语文》（教育部组织编写、人教社出版），不是普通的统编版。小学1–5年级用一至五年级册，初中6–9年级用六至九年级册。上海六年级（预备）用五·四学制六年级上下册，内容和六三制小学六年级册不一样：比如五·四学制六下（2025版）包含鲁迅单元、“遨游汉字王国”、整本书《林海雪原》，没有快乐读书吧和口语交际。
   来源：上海市教委2025秋目录 https://edu.sh.gov.cn/cmsres/3e/3e72a3d43d05429e9325d4b57cf499c3/f1b8612f871c899afe807885f18ad0aa.pdf ；教育部2024教学用书目录 http://www.moe.gov.cn/srcsite/A26/s8001/202408/t20240805_1144254.html
2. 整套书正在换新版：修订教材2024秋从起始年级开始用，2026秋全部年级换完（ http://www.moe.gov.cn/jyb_xwfb/s5147/202408/t20240828_1147579.html 、 http://www.moe.gov.cn/jyb_xwfb/s5147/202609/t20260907_1449516.html ）。包里的单元号大多按旧版写。已确认的变化：三上第三、四单元互换；一上识字量300→280；七上改为“整本书阅读”和“专题学习活动”（人教社 https://www.pep.com.cn/xw/zt/hd/12/zbtjc/202410/t20241015_1995856.html ）。
3. 高中：“必修上第三单元（小说）”写错了，必修上第三单元是古诗词，小说在第一单元。上海高二上用选必上、高三上用选必下（2025秋目录），所以WT-17的term应为“上”。选必下的内容放在G12，包里完全没覆盖。
4. 已补高中缺的单元：必修上第4、7单元；必修下第1、4、5、8单元；选必上第1单元；选必中第1、2、4单元；选必下第1–4单元。
5. fix 16条（涉及14个知识点），add 20条，remove 0条，unverified 11条。
