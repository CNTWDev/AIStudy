# phy-cambridge 校对报告（Cambridge Lower Secondary 0893 → IGCSE Physics 0625）

数量：来源 7 个（官方 5、佐证 2）。fix 41 条（desc 34、name 4、stage 2、level 1），add 16 个，remove 0，unverified 6 条。

## 结论
- **IGCSE 0625**：1.1–6.2.3 共 45 个小节全部覆盖，编号无误。主要问题是 Core 和 Supplement 混标，已全部通过修改 desc 或 name 纠正，没有改动任何 id。
- **最重要的 5 个问题**
  1. 6.1.2 的光传播时间属于 Core。v=2πr/T 应归入 6.1.1 S4。
  2. 1.2-03 与 1.2-04 的 Core/Supp 放反了（v-t 图面积、g≈9.8 两项，以及 a=Δv/Δt）。
  3. 1.5.1-01 应标为 core。
  4. 1.7.3-02 中的效率公式属于 Supplement。
  5. 有三处缺漏，已各新增一个点：4.2.1 电场（S7–10）、4.5.4 S3 带电粒子束、6.1.2 S7/8/10 椭圆轨道与行星数据。
- **Lower Secondary 0893**：原来只有 5 个 SCI-PRE 点，现补到 18 个，新增 13 个（声、太阳系、速度、力矩、压强、色光、磁、资源、星系、密度、热、波形、电阻）。
- **年级对应**：Stage 7/8/9 对应 G6/G7/G8，IGCSE 对应 G9–G10。据此 SCI-PRE-ENERGY 由 G7 调为 G6，SCI-PRE-LIGHT 由 G8 调为 G7。
