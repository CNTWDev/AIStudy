# AIStudy 家庭学习系统

给孩子用的网页版学习系统：每个孩子用自己的邮箱登录，家长有总览页。
同一套系统，换一份教材数据就能覆盖小学、初中、高中和国际课程。

**能做什么**

- **每天一张任务清单**：孩子打开「今天」从上往下做就行，不用到处找入口。顺序固定：
  （进度提醒）→ 单词（新词 + 查过收藏的词 + 到期复习）→ 错题回顾 → 英语阅读 → 名著接着读 → 跟上学校 → 试卷订正 → 补弱 / 补前置 → 回顾小检查 → 预习。
  单词、错题、阅读每天都有；学知识点的任务按每天可用时间截断。做完一项得一颗 ⭐（不管对错，**坚持比做对更重要**），连续打卡有徽章。
- **一日记录**：每天自动汇总做了几项、学了多久、做了多少题、读了哪一章、查了哪些词，加一句心情和反思；日历里点任何一天都能回看。
- **学校学到哪了（课程进度）**：每隔一两周花 1 分钟选「正在学」并勾上学过的。计划据此安排：跟上学校正在学的 → 回头抽查学过的 → 补前面没打牢的前置 → 提前看一眼下一个。超过两周没更新，清单第一项会提醒。
- **试卷订正与诊断**：测验、月考拍照上传（或粘贴文字），AI 拆成一道道题、对上知识点、读出老师的批改。原卷错题自动进错题本；孩子在线再做一遍，最后出诊断：真不会的、可能粗心的、要往回补哪些基础。
- **阅读与单词安排**：家长选书（内置 75 本中文名著和 50 本英文分级读物，西游记、三国演义等带回目），每天读多少、多长时间；选一份分年级词表每天学几个新词。
- **不知不觉摸底过去**：孩子不管几年级进来，系统都不知道他以前学得怎么样。每天清单最前面有个 4 分钟的「热身」，几道小题混着以前学段的知识点和旧单词；做知识点练习时也会穿插一道「以前学过的」。系统挑信息量最大的点来测：答对就点亮它，并推断它的前置也大概率掌握；答错就沿前置往回追，接下来几天接着测。英语旧单词四选一闪测，不认识的自动进单词复习，还会估算词汇量。「今天」页和家长页能看到每科「以前学过的内容摸清了多少」。
- **前方引导**：「今天」页的「🧭 前方」告诉孩子每科的下一站是什么、准备好了几成、先练熟哪个前置会更轻松、学会后能去学什么。
- **知识背景**：每个知识点讲清楚「从哪来、用在哪」，加一个让人「哇」的小事实（AI 生成，按知识点缓存）；做完题提示「学会它能做什么」。
- **激励：少而有效**：连对计数（🔥）、第一次真正掌握一个知识点时「🌟 点亮」、学习地图一点点变亮；加上原有的每日 ⭐ 和连续天数徽章。只奖励真实的进步，不刷分。
- **跟自己比，越学越想学**：不做排行榜、积分商城和抽奖，只跟自己比。⏱ 专注计时（页面切走或一分钟没动静就停表）；做单词复习、错题回顾、热身时，进度条上有个 👻「上周的我」按上周的速度在跑；每组做完自动比个人最好（PB：答对最多、每题最快、最长连对、最长专注），破了就弹「🏅 新 PB！」。正确率不到 80% 的一组不算纪录，免得为了快乱答。每周一「今天」页展开「📈 上周进步卡」，只写比再上一周进步的地方；家长页也能看到。
- **🎮 乐园：比的是专注，不是会多少**：三款游戏：「火柴人大战」（答题补能量，出拳、换武器、放必杀打电脑）、「闪电赛跑」（答对冲刺，和「上次的我」赛跑）、「星星守卫」（答对放魔法守城堡）。题目按每个孩子自己的水平出（能力值和难度在线校准），可选数学口算、英语单词和课本术语、学过的知识点上的短选择题，同一个班水平不同的孩子赢的机会也差不多，谁更投入谁更容易赢；战报里的「专注指数」= 实际答对 ÷ 预期答对。管理后台有公平看板。家长设每天玩多久、什么时候解锁（默认做完一半任务），做完全部任务、点亮知识点能多玩几分钟。只奖励真做到的事：贴纸、解锁角色、乐园等级，没有排行榜和抽奖。游戏里答题按半权计入掌握度，每局有战报告诉孩子练了什么。
- **网站里随手划词**：孩子在网站任何页面选中文字，就弹出菜单：🔍 查词、🌐 翻译句子、➕ 加入复习、🙋 问小助手。系统按行为自动记录：同一个词或句子查第二次、做题时查的，自动放进复习，不用孩子手动加。页面顶部还有「🔎 查词」。在「阅读」里贴一个网页链接，正文会放进站内阅读器，点词就查。
- **划词查词插件**（可选，Chrome / Edge）：想在别的网站上也这样查词，可以装插件（「账号」页里的「浏览器插件」）。
- **问一问小助手**：孩子的每个页面右下角都有「🙋 问小艾」（名字和图标可以在 `.env` 的 `ASSISTANT_NAME` / `ASSISTANT_ICON` 里改），会自动带上正在做的那道题或选中的文字。小艾永远不直接给答案，而是把问题拆成小步、一问一答地引导；孩子做完题后才讲为什么。诊断时不出现。家长在学习报告里能看到孩子问过什么。
- **自动发现问题**：系统不只看「做错了」，每天从孩子的整个学习过程里主动找信号——几个薄弱点共用的**根源前置**、反复点「还不会」、
  同一个知识点问了好几次、**做对了但很慢**（不熟练）、复习时总忘的词、查了好几次的词（自动加进单词本）、很久没练的已掌握内容、
  考试会做却丢分（粗心），以及给家长看的习惯提醒（这周只学了几天、某本书好几天没读）。发现的问题会自动变成今天的任务，
  最重要的一条排在「跟上学校」之后、不会因为时间不够被截掉；问题解决了会自动关闭。
- **做题更友好**：每道题都有「🤔 这道题还不会」，不算错，直接看讲解并进错题本；答对有小动画。
- **摸底诊断**：从孩子当前学段出题，做错了自动往回追前置知识（最多 3 层），找到真正的「断点」。
- **一步步学一个知识点**：看懂 → 记方法 → 做 3 题（从易到难，有提示）→ 一句话总结；连错两题会提示「退一步」去补前置。
- **间隔复习**：生词、错题、术语、知识点总结都变成卡片，按 1/2/4/7/15/30 天出现。
- **AI 阅读**：AI 按孩子水平写短文（自动用上要复习的生词），或者粘贴自己的书；点词即查，用生词造句让 AI 点评。
- **成人备考**：家人也可以用来考证（例如基金从业资格）。添加学习者时年级选「成人」：AI 用成人的口吻讲解，不显示乐园，不先摸底。
  在「学习进度和考试日期」里设好考试日期，系统按剩下的天数算出每天要学几个考点，按大纲顺序排进「今天」；离考试两周时不再学新内容，改成把还没掌握的高频考点过一遍。孩子的课（如 IGCSE）也可以设考试日期。
- **家长与管理**：家长账号只查看和管理（看孩子今天的清单、报告和系统发现，安排阅读、更新进度、导入试卷），孩子用自己的账号学习；网站管理员有单独的管理后台：站点设置、数据统计、审批、邀请码、查看每个孩子的情况。

## 安装（一台新的云服务器，一条命令）

准备：一台 Linux 云服务器（推荐 Ubuntu 24.04 / 22.04，1 核 1–2 GB 内存即可），可选一个已解析到服务器 IP 的域名。
用 root 或能 sudo 的用户登录服务器，运行：

```bash
# 有域名：自动配置 HTTPS（安全组放行 80、443）
curl -fsSL https://raw.githubusercontent.com/CNTWDev/AIStudy/main/install.sh | sudo bash -s -- install --domain study.example.com

# 没有域名：先用 http://服务器IP:8000 访问（安全组放行 8000）
curl -fsSL https://raw.githubusercontent.com/CNTWDev/AIStudy/main/install.sh | sudo bash -s -- install

# 服务器在中国大陆：再加 --mirror cn（用国内 pip 镜像）
```

脚本自动完成：

1. 检测环境（系统、内存、磁盘、Python、PostgreSQL、端口、域名解析）
2. 安装依赖（git、Python 3.10+、PostgreSQL；有域名时装 Caddy）
3. 拉取代码到 `/opt/aistudy`
4. 生成配置 `.env`（随机密钥、数据库地址）和 `config/llm.toml`（AI 配置模板）
5. 创建 PostgreSQL 数据库和用户
6. 安装 Python 依赖、执行数据库迁移
7. 注册开机自启服务 `aistudy`，配置 HTTPS，健康检查，打印访问地址

## 第一次使用

系统里有三种账号：

| 账号 | 谁用 | 能做什么 |
|---|---|---|
| 网站管理员 | 搭网站的人 | 管理后台：站点设置、数据统计、审批注册、邀请码、查看每个家庭和孩子的情况。不带孩子，不做题 |
| 家长 | 爸爸妈妈 | 添加孩子、安排阅读和单词、更新学校进度、导入试卷、看孩子的清单和报告。只查看和管理，不替孩子做题 |
| 孩子 | 孩子本人 | 用自己的邮箱登录后才是学习状态：今天的任务、做题、阅读、复习、问小助手 |

1. 打开网址，**第一个注册的账号是网站管理员**（不需要邀请码）。
2. 管理员在「管理 → 家庭与孩子」底部给自己（以及家人）创建**家长账号**，或者在「管理 → 邀请码」生成邀请链接。
3. 用家长账号登录，在「家长页 → 添加孩子」给每个孩子创建账号：名字、登录邮箱（只当登录名，不需要能收信）、密码、年级、每门课用的教材版本（学段按年级自动对应）。以后在「资料与密码」里可以改名字、邮箱、年级、教材，重置密码、解除锁定、让孩子在所有设备上退出登录。
4. 孩子在自己的手机 / 平板 / 电脑上用自己的邮箱登录；手机浏览器里可以「添加到主屏幕」。
5. 其他家庭想用：管理员或家长生成邀请链接发给对方（**邀请码只用来注册家长账号**），对方注册后直接开通；
   没有邀请码的人也能提交申请，管理员在「管理 → 概览」里审批。

## 配置 AI（Claude 等）

```bash
sudo nano /opt/aistudy/config/llm.toml
```

在 `[providers.claude]` 的 `api_key` 填上 [Anthropic Console](https://console.anthropic.com) 申请的 Key（`sk-ant-...`）。
服务器在中国大陆或香港时，Claude API 不可用，把 `default` 改成 `"deepseek"` 并填 DeepSeek / 通义千问的 Key。改完：

```bash
sudo systemctl restart aistudy
sudo /opt/aistudy/install.sh check --llm      # 真实调用一次 AI，确认能用
```

不配 AI 也能用：诊断、现成题库练习、复习、记录照常；查词、讲解、AI 出题、AI 写短文需要 AI。

## 升级

```bash
sudo /opt/aistudy/install.sh upgrade
```

自动：拉取 GitHub 最新代码 → 备份数据库到 `/opt/aistudy/data/backups` → 更新依赖 → 执行新的数据库迁移 → 重启 → 健康检查。
`.env`、`config/llm.toml` 和所有数据都会保留。升级失败时脚本会打印回退命令。

## 日常运维

| 要做什么 | 命令 |
|---|---|
| 检查是否一切正常 | `sudo /opt/aistudy/install.sh check`（加 `--llm` 测 AI） |
| 状态 / 日志 / 重启 | `sudo /opt/aistudy/install.sh status` / `logs` / `restart` |
| 立即备份数据库 | `sudo /opt/aistudy/install.sh backup` |
| 每天凌晨自动备份 | `echo '30 3 * * * root /opt/aistudy/install.sh backup' \| sudo tee /etc/cron.d/aistudy-backup` |
| 家长忘记密码 | 管理员在「管理 → 家庭与孩子」点家长名字进「账号管理」，重置成临时密码（对方登录后必须先改成自己的），或改发重设密码链接 |
| 孩子忘记密码 | 家长在「家长页 → 资料与密码」里直接重置 |
| 管理员自己忘记密码 | `cd /opt/aistudy && sudo -u aistudy .venv/bin/python -m app.cli reset-password 邮箱 新密码` |
| 账号被锁（连续输错 5 次） | 等 15 分钟；或家长 / 管理员在账号页点「解除锁定」；或 `sudo -u aistudy .venv/bin/python -m app.cli unlock 邮箱` |

更多（私有仓库安装、Docker、恢复备份）见 [docs/DEPLOY.md](docs/DEPLOY.md)。

## 两个配置文件

| 文件 | 管什么 |
|---|---|
| `.env` | 服务器、数据库地址、注册方式（`REGISTRATION`）、登录安全策略（安装脚本自动生成） |
| `config/llm.toml` | AI：用哪家（Claude / DeepSeek / 通义…）、模型、API Key、每日上限、按任务指定模型 |

注册方式 `REGISTRATION`：`approval`（默认，有邀请码直接开通，没有的需管理员审批）/ `invite`（必须邀请码）/ `open` / `closed`。

## 账号与管理后台

- 邮箱 + 密码登录；改密码后其他设备自动下线；可查看和退出登录中的设备；连续输错 5 次锁定 15 分钟。
- **管理后台**（管理员可见，页面顶部「管理」）：
  - 概览：家庭数、孩子数、近 7 天在学人数、**待审批申请**（通过 / 拒绝）
  - 数据统计：近 14 天每天的在学孩子数、学习分钟、做题数、提问数、AI 调用次数；每个孩子近 7 天的学习天数、正确率、「还不会」次数、系统发现的问题数
  - 站点设置：网站名称、提问小助手的名字和图标、注册方式、家长邀请码上限（保存后立即生效，不用改服务器文件）
  - 家庭与孩子：每个家庭的家长、邀请人，以及每个孩子的年级、教材、今天完成情况、连续坚持天数、本周学习时长、待复习和生词数、薄弱点，可打开学习报告；停用 / 启用、设为管理员；点名字进「账号管理」：改名字和邮箱、重置密码（临时密码或重设链接）、解除锁定、退出所有设备、查看最近的账号记录
  - 邀请码：生成（次数、有效期、备注）、作废、看每个码被谁用了
  - 邀请关系：谁邀请了谁的树状图
  - 安全日志、系统状态（版本、数据库、AI、迁移）
- 从旧版本升级：原来「第一个注册的家长」账号保留家长和管理员两种身份，什么都不用改；以后新建的管理员是独立账号。

## 给孩子用起来（家长要做的 4 件事）

1. **家长页 → 添加孩子**：邮箱（只当登录名）、密码、年级、每门课的教材版本（不用再选学段，按年级自动对应）、每天能学多少分钟。
2. **家长页 → 阅读与单词**：选一本中文名著（每天接着读几回）、一本英文读物、一份词表（每天几个新词）。页面下方有两个孩子的示例安排可以参考。
3. **家长页 → 学校进度**：每门课选「学校正在学」，勾上本学期已经学过的。之后每一两周更新一次。
4. **电脑上装查词插件**：页面顶部「查词工具」→ 下载插件 → 按页面步骤装到 Chrome / Edge → 生成连接码填进去。

之后孩子每天只要打开「今天」从上往下做。考试、测验后，在「学科 → 导入试卷」拍照上传。

**试卷拍照解析需要能看图片的 AI 模型**：Claude 可以直接用；DeepSeek 目前不能看图，可以在 `config/llm.toml` 里给 `[tasks.paper]` 单独指定通义千问的 `qwen-vl-max`（文件里有注释示例），或者在导入时改用「粘贴题目文字」。试卷照片保存在服务器的 `data/papers/` 目录。

## 本地开发

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env            # 默认 SQLite，无需安装数据库
uvicorn app.main:app --reload   # 打开 http://localhost:8000
python -m pytest -q
```
